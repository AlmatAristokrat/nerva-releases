# NERVA Desktop — установщики

Публичные сборки приложения NERVA для Windows и macOS.

- Windows: `NERVA-<version>-setup.exe`
- macOS Apple Silicon: `NERVA-<version>-arm64.dmg`
- macOS Intel: `NERVA-<version>-x64.dmg`

Пилотные сборки без коммерческой подписи: Windows SmartScreen → «Подробнее» → «Выполнить всё равно»;
macOS — правый клик по приложению → «Открыть».
